# Проект управления товарами и категориями

## Функционал проекта

Проект реализует систему управления товарами и категориями с возможностью:
* создания продуктов с указанием названия, описания, цены и количества;
* создания категорий с описанием и списком товаров;
* автоматического подсчёта количества категорий и товаров;
* загрузки данных из JSON-файла.

Для класса Product переопределен метод str , который возвращает строку: Название продукта, X руб. Остаток: X шт.

Для класса Category переопределен метод str , который возвращает строку: Название категории, количество продуктов: X шт.

Для класса Product переопределен магический метод сложения add , который принимает два аргумента:self и второй объект.
